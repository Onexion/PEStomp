# PEStomp
Ussage:

PEStomp.exe <PEStomp.exe> --year <start> <end>     random year in range<br>
PEStomp.exe <PEStomp.exe> --random                 random 1990–2030<br>
PEStomp.exe <PEStomp.exe> --zero                   set to zero<br>
PEStomp.exe <PEStomp.exe> --now                    current timestamp<br>
PEStomp.exe <PEStomp.exe> --set <hex>              custom value<br>
